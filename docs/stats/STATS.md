## 3. Token cost of the tool list

This is the cost of the `tools/list` answer. The estimate is the estimate of the repository: 3.5 characters for each token (`scripts/ste_check.py`, `agentlink/usage.py`). It is not the count of the provider. The server instructions are not in these numbers.

| Mode | Style | Tools listed | Characters | Tokens (est.) |
|---|---|---:|---:|---:|
| static (default) | ste | 6 | 5,542 | 1,583 |
| static | full | 6 | 14,303 | 4,087 |
| classic | ste | 22 | 20,514 | 5,861 |
| classic | full | 22 | 28,972 | 8,278 |

With every hub group turned on, the list has 415 tools, 334,676 characters and about 95,622 tokens (style full).

- static: only the base is listed (`session_state`, `batch`, `guide_read`, `tool_find`, `approve_file`, `approve_code`). The agent finds the other tools with `tool_find`.
- classic: the lean groups are listed (`core`, `view`).
- ste: the descriptions in `agentlink/data/ste.json` replace the full text for `batch`, `guide_read`, `session_state`, `tool_find`. The other tools keep their full text.

### Extra tokens for each add-on

An add-on that is not installed adds 0 tokens. This is a rule of the project: Agent Link lists no tool of an add-on that is not installed. In static mode an installed add-on also adds 0 tokens, until the agent turns on one of its groups with `tool_groups`. The style has no effect on add-on tools: `ste.json` holds hub tools only.

| Add-on | Not installed | Static | Classic (lean groups) | All its groups on |
|---|---:|---:|---:|---:|
| AgentLink-OrcaSlicer | 0 | 0 | 0 (0 tools) | 6,878 |
| ScanRuler-FreeCAD | 0 | 0 | 0 (0 tools) | 67,288 |
| Texturizer-FreeCAD | 0 | 0 | 0 (0 tools) | 11,092 |
| Tutor-FreeCAD | 0 | 0 | 0 (0 tools) | 3,442 |
| Workshop-FreeCAD | 0 | 0 | 4,717 (11 tools) | 30,659 |

### What is approximated

- Each token number is an estimate: characters divided by 3.5.
- 25 hub tools have an input schema in code that the script cannot read as data. For these tools, the script uses the length of the schema source text plus 40 characters, as `ste_check.card_tokens` does. The static base has 6 such tools. The classic list has 17 such tools.
- 18 add-on tools have such an estimated entry (a schema or a description in code).
- The script counts a FreeCAD build with every workbench. A build without a workbench (FEM, CAM …) serves fewer tools.
- The add-on numbers come from the snapshot. Run `python3 scripts/stats.py --addons <folder with the add-on checkouts>` to make it again.

## 4. Timings

No timing data in the repo yet. The findings files give times in prose only, and the script does not read prose.

To add timings, run `python3 scripts/stats.py --timings <file>`. The file is one day of the Agent Link usage log (`~/AgentLink/usage/<day>.jsonl`) or the heavy-job queue (`queue.json`). The script keeps the tool names and the times only. It writes `docs/stats/timings.json`, and this section shows the median for each tool family.
